¿Cómo usar este programa?

Esta semana el objetivo no es hacerlo perfecto, sino volver a cumplir una estructura simple y sostenible: Lunes, miércoles y sábado (disponibilidad; planificación pendiente). Versión provisional, pendiente de evaluación funcional.
